# DriftGuard Mobile

This repository holds the Frequency Guardian Android approval app, the Rust approval broker, deployment units, the production monitor and their scripts and docs, extracted from `altrudev/MCP-DriftGuard` at commit `f7d86a12be6ea847075f21a8d0db62d97bba7867` so the DriftGuard core can stand alone.

Companion to the standalone verifier at [altrudev/MCP-DriftGuard](https://github.com/altrudev/MCP-DriftGuard), which does not depend on anything here. Paths are unchanged from the original layout; some scripts still expect to run beside the DriftGuard core.
