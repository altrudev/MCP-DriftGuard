# Governance

## Current state

MCP DriftGuard is maintained by a single maintainer:

| Maintainer | GitHub | Affiliation |
|---|---|---|
| Valentyn Rukhaylo | @altrudev | Altru.dev |

Decisions are made by the maintainer after discussion in public issues and pull requests. This file states the current position plainly; it does not claim a multi-organization governance structure that does not yet exist.

## Becoming a maintainer

A contributor who has landed several substantial, reviewed pull requests and participated in issue triage may be invited to become a maintainer. New maintainers are announced in a pull request that updates this file, and accept by approving it.

## Direction

The project aims for vendor-neutral governance. Once there are maintainers from at least two independent organizations, decisions will move to lazy consensus among maintainers, with a simple majority vote when consensus fails, and the project may seek a home in a neutral open-source foundation.

## Code of conduct

Be respectful and assume good faith. The maintainers may remove comments, commits or contributors that are abusive or harassing.
